# 📘 CSS NOTES (BASICS + SELECTORS)

---

## 🎯 TYPES OF CSS

### 1. Inline CSS

* Applied directly inside HTML elements

```html
<p style="color: red;">Text</p>
```

✔ Quick use
❌ Not scalable, messy

---

### 2. Internal CSS

* Written inside `<style>` in `<head>`

```html
<style>
  p {
    color: blue;
  }
</style>
```

✔ Good for single page
❌ Not reusable

---

### 3. External CSS ✅ (Best Practice)

* Separate `.css` file

```html
<link rel="stylesheet" href="style.css">
```

```css
p {
  color: green;
}
```

✔ Clean
✔ Reusable
✔ Professional approach

---

## 🎯 CSS SELECTORS

### 1. Element Selector

```css
p {
  color: blue;
}
```

Targets all `<p>`

---

### 2. ID Selector

```css
#header {
  background: black;
}
```

✔ Unique element only

---

### 3. Class Selector ⭐ (Most Used)

```css
.box {
  border: 1px solid red;
}
```

✔ Reusable

---

### 4. Group Selector

```css
h1, p {
  color: green;
}
```

---

### 5. Universal Selector

```css
* {
  margin: 0;
}
```

---

### 6. Descendant Selector

```css
div p {
  color: purple;
}
```

Targets `<p>` inside `<div>`

---

### 7. Child Selector

```css
div > p {
  color: orange;
}
```

Only direct children

---

### 8. Attribute Selector

```css
input[type="text"] {
  border: 1px solid blue;
}
```

---

### 9. Pseudo-class

```css
a:hover {
  color: red;
}
```

---

### 10. Pseudo-element

```css
p::first-letter {
  font-size: 30px;
}
```

---

## ⚡ CSS PRIORITY (IMPORTANT)

Highest → Lowest:

1. Inline CSS
2. ID Selector
3. Class Selector
4. Element Selector

👉 This decides which style is applied when there’s conflict.

---

## ⚠️ COMMON MISTAKES

* Using too many IDs
* Writing complicated selectors
* Ignoring CSS priority
* Not practicing layouts

---

## 🚀 WHAT TO FOCUS ON

* Class selectors
* Box model (margin, padding)
* Flexbox (next step)
* Real practice (build small UI)

---

## 🔥 SIMPLE RULE

If your CSS feels confusing, it’s because:

* Your selectors are messy
* Or you don’t understand priority

Fix those, and things start making sense fast.
